# OpenList Manager v1.4.0

本版本新增任务详情：任务中心里的每条任务都能查看完整的源路径、目标路径和错误信息，不再被截断。「概览」和「我的」也重新整理了入口，服务器管理相关的功能集中到「概览」，「我的」只保留和 App 本身相关的设置。另外修复了滑动返回时页面重影、外挂字幕损坏导致视频无法播放等问题。

---

## 新增

### 任务详情

以前任务中心的卡片只能显示一行任务名称，路径一长就看不全，失败原因也只显示两行。

现在点击任务卡片，或卡片底部的「详细」，会弹出任务详情：

- 复制、移动、上传、离线下载、解压等任务会拆出「源路径」和「目标路径」，显示完整路径。
- 失败任务显示完整的错误信息，进行中的任务显示进度和当前阶段，进度随列表自动刷新。
- 同时显示大小、创建者、开始与结束时间、耗时和任务 ID，文字都可以长按复制。
- 详情底部同样可以取消、重试或删除任务。

### 更新弹窗排版

检查到新版本时，更新弹窗里的更新日志现在会按小标题、列表和加粗来排版，不再显示 #、** 之类的符号。

---

## 变更

- **「概览」的快捷入口调整为任务队列、用户管理、系统设置、服务器连接**。原来的「文件管理」「挂载管理」和底部的「文件」「存储」重复，所以去掉了。
- **「概览」右上角的按钮改为「切换服务器」**。应用设置的入口在「我的」里。
- **「我的」精简为应用设置、服务器连接、关于和退出登录**。「外观与主题」并入「应用设置」，服务器名称和版本改为显示在账号卡片里。

---

## 修复

- **解压任务的名称会显示压缩包的密码**。任务中心里压缩包密码现在一律显示为 `<***>`。
- **滑动返回时，上一页和当前页的内容叠在一起**。现在返回时会显示完整的页面。
- **外挂字幕文件内容损坏时，整个视频都无法播放**。现在会去掉这条字幕后继续播放，并提示字幕加载失败。
- **视频还没加载完就退出，之前保存的播放进度会被清除**。现在会保留原来的进度。
