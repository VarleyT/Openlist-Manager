# OpenList Manager v1.4.2

本版本任务中心可以看到传输速度和预计剩余时间，上传通知里也会同步显示；另外修复了自动重试中的任务仍显示红色报错、容易误以为任务出错的问题。

---

## 新增

### 传输速度与剩余时间

以前任务中心只显示进度百分比，看不出任务传得快不快、还要多久。

现在进行中的任务卡片和任务详情会显示当前速度和预计剩余时间，已完成的任务显示平均速度。

- 本机上传的速度按实际发送的数据计算，任务中心和通知栏同时显示。
- 服务器上的任务（如复制、离线下载）不提供实时速度，按进度变化估算，刚开始的几秒不显示。
- 任务大小未知时不显示速度和剩余时间；任务重试导致进度回退时会重新计算。

---

## 修复

- **自动重试中的任务仍显示红色错误信息**。服务器重试任务时会保留上一次的错误，看起来像是当前出错了。现在等待、运行和等待重试中的任务改为用警告色显示「上次尝试失败」，真正出错或失败的任务显示不变。
