# OpenList Manager v1.3.1

本版本让播放器可以播放 DTS、TrueHD、AC3、E-AC3 等格式的音频。这些格式在蓝光原盘、Remux 和高码率电影里很常见，但大多数手机系统不自带对应的解码器，上一版遇到它们只能无声播放。现在手机自己解不了时，会改用 App 内置的软件解码器，画面仍然用手机的硬件解码。

---

## 新增

### 支持 DTS、TrueHD、AC3 等音频

App 内置了 FFmpeg 音频解码器，作为手机系统解码器的补充。

- 能播放的格式包括 DTS（含 DTS-HD 的核心音轨）、TrueHD、AC3、E-AC3 和 ALAC。
- 手机系统支持的格式仍优先使用系统解码器，只有系统解不了时才会用内置解码器，不影响普通视频的播放和耗电。
- 「音轨与字幕」里，这些音轨不再标注「设备不支持」，多条音轨时可以正常切换。
- 蓝光原盘格式（m2ts）里的 DTS 音轨现在也能识别。

---

## 变更

- **安装包从约 5.7 MB 增加到约 10.4 MB**，增加的部分是内置音频解码器，覆盖 arm64-v8a、armeabi-v7a、x86、x86_64 四种处理器架构。
- **使用 FFmpeg 的说明**：内置解码器基于 FFmpeg 6.0 构建，只包含上面列出的音频解码器，采用 LGPL 许可，App 本身仍为 MIT 许可。

---

## 修复

- **播放 DTS / TrueHD 音轨的视频时只有画面没有声音**。上一版会提示「设备不支持该视频的音频编码」，现在可以正常出声，5.1 等多声道音轨由系统按手机的扬声器或耳机混音输出。
