# OpenList Manager v1.1.0

本版本让存储驱动显示中文名称，选择驱动时也能用中文搜索。同时加强了登录凭据的保护：访问第三方网盘直链时不再附带 OpenList 的登录凭据。另外修复了切换服务器后后台上传传错服务器、退出登录后又被自动登录回去、搜索结果只有第一页等问题。

---

## 新增

### 驱动显示中文名称

新建存储时的驱动列表、编辑存储页和存储卡片上，驱动名称改为显示中文（翻译来自 OpenList 官方前端），例如「百度网盘」「夸克网盘」。

- 选择驱动时，列表标题显示中文名，下面保留驱动的原始名称。
- 搜索驱动时，中文名和原名都能搜到。
- 没有中文翻译的驱动照常显示原名。

---

## 变更

- **访问第三方网盘直链时不再附带 OpenList 登录凭据**。很多存储的文件地址指向第三方网盘，以前预览图片和文本、下载文件时，登录凭据可能被一起发给这些第三方地址。现在只有发往你的 OpenList 服务器本身的请求才会带上凭据。
- **使用 http 连接的提示更准确**。登录页会按补全协议后的实际地址判断是否为不安全的 http 连接，并显示对应的锁图标。

---

## 修复

- **上传过程中切换服务器，文件会被传到新切换的服务器上**。现在每个上传任务固定在发起时的服务器上完成；App 被系统关闭后重新启动，也会继续传到原来的服务器。
- **退出登录或移除服务器后，后台上传仍在继续**。现在会一并取消该服务器的上传任务。
- **登录过期自动重新登录时，可能把当前服务器换回之前的服务器，或在退出登录后又自动登录回去**。现在只会为当前服务器重新登录，退出登录后不会再自动登录。
- **搜索结果只显示第一页**。现在滑到底部会继续加载更多，重复的结果会去掉。
- **移除当前正在使用的服务器后，页面停在原处无法使用**。现在会回到登录页。
- **服务器地址只填了协议、没填主机也会去连接**。现在登录时会提示「服务器地址格式无效」。
