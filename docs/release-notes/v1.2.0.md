# OpenList Manager v1.2.0

本版本新增了检查更新。可以在「关于」页手动检查，App 启动时也会自动检查，有新版本时弹窗显示更新内容，点「前往下载」在浏览器中打开下载页。「关于」页还加上了项目仓库的链接。

---

## 新增

### 检查更新

- 在「我的 → 关于」里点「检查更新」，会显示当前版本，以及是否有新版本。
- 发现新版本时弹窗显示更新内容，点「前往下载」会在浏览器中打开该版本的下载页面。
- 检查失败时会说明原因，例如网络异常，或请求过于频繁需要稍后再试。

### 启动时自动检查

- App 启动后在后台检查一次，有新版本时弹窗提醒，不影响启动速度。
- 24 小时内最多检查一次；检查失败时不打扰你。
- 提醒弹窗里可以选「忽略此版本」，之后这个版本不再自动提醒，有更新的版本时照常提醒；在「关于」页手动检查不受影响。
- 「我的 → 应用设置 → 更新」里可以关闭「启动时检查更新」。

### 项目仓库链接

「关于」页新增「项目仓库」，点击在浏览器中打开 GitHub 上的项目主页，可以查看源码、提交问题。

---

## 变更

- **检查更新只访问 GitHub**。检查和下载更新只会访问 GitHub，不会附带你的 OpenList 登录凭据；下载链接也只会打开 GitHub 上的页面。
