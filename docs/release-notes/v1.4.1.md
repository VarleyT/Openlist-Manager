# OpenList Manager v1.4.1

本版本主要改进任务中心和文件页：任务中心支持长按多选，可以批量取消、重试或删除任务，「已完成」页的清理选项和网页端对齐，「进行中」页可以一键取消全部任务；文件页右上角改为后台任务入口和「更多」菜单，有任务在执行时会显示数量角标。另外修复了大文本文件打开卡顿、播放器锁屏按钮与「上一个」重叠等问题。

---

## 新增

### 任务批量操作

以前任务中心只能一条一条地取消、重试或删除任务，记录一多清理起来很麻烦。

现在长按任务卡片进入多选，可以勾选多条任务或点「全选」，再用底部的按钮批量处理：

- 「进行中」页可以批量重试或取消，「已完成」页可以批量重试或删除。
- 有任务处理失败时会提示失败的数量和原因，其余任务照常处理。
- 按返回键或点左上角的关闭按钮退出多选。

### 取消全部任务

「进行中」页右上角的菜单新增「取消全部」，可以一次取消列表里所有进行中和等待中的任务。选了任务类型时只取消该类型的任务，执行前会弹窗确认。

### 后台任务角标

文件页右上角新增后台任务按钮，点击进入任务中心。有任务正在执行时，按钮上会显示数量角标，停留在页面上时角标会自动刷新，任务全部结束后角标消失。

---

## 变更

- **「已完成」页的清理选项调整为「重试失败项」「清除成功项」「清除全部」**。和网页端一致：「清除成功项」只删除成功完成的记录，失败和已取消的会保留下来方便重试；「清除全部」会删除所有已结束的记录。每项操作前都会说明影响范围并确认。
- **文件页右上角改为后台任务按钮和「更多」菜单**。排序方式和显示方式都放进了「更多」菜单，点「显示方式」展开后可以选择列表或网格。原来放在「新建」菜单里的「查看后台任务」已移除。
- **存储卡片新增「更多」按钮**。启用、禁用和删除存储不再只能长按卡片。
- **应用设置里点击整行即可切换开关**，不用再对准开关按钮。
- **系统设置的下拉选项显示中文名称**。
- **新建用户时默认允许 LDAP 登录**，和服务端直接创建用户时的行为一致。

---

## 修复

- **打开较大的文本文件时界面卡顿**。现在文本按需逐行加载，大文件也能流畅滚动。
- **竖屏播放视频时，锁定按钮和「上一个」按钮重叠**。锁定按钮已移到进度条上方。
- **播放器锁屏后按返回键仍会退出播放**。现在锁屏期间返回键不起作用，需先解锁。
