# OpenList Manager v1.0.0

OpenList Manager 的第一个版本。这是一个用来远程管理 OpenList v4 服务器的 Android 客户端，可以在手机上浏览和管理文件、维护存储挂载、管理用户、查看任务、修改站点设置，同时支持连接多台服务器。支持浅色、深色和跟随系统三种主题。

---

## 新增

### 登录与多服务器

- 用用户名和密码登录 OpenList，开启了两步验证的账号可以输入验证码。
- 可以添加多台服务器，随时切换或移除。地址只填域名或 IP 时会自动补全协议：局域网地址默认 http，其他默认 https；使用 http 连接时登录页会提示风险。
- 登录凭据使用 Android 系统密钥库加密保存，不参与云备份。

### 服务器概览

首页显示服务器在线状态、存储挂载统计（总数、正常、异常），以及文件、挂载、任务、用户的快捷入口。有挂载异常时会列出异常的存储和原因，点击可以跳到挂载管理处理。

### 文件管理

- 浏览目录，用顶部的路径导航快速返回上级；可以切换列表和网格布局，按名称、大小、修改时间排序。
- 上传文件、新建文件夹，以及重命名、复制、移动、删除；长按进入多选，可以批量操作。
- 搜索文件和文件夹（需要在 OpenList 后台开启搜索索引）。
- 上传在后台进行，通知栏显示进度，网络中断后会自动重试。

### 文件预览

图片可以双指缩放查看，文本和代码文件可以直接预览。其他格式可以用手机上的其他应用打开，也可以下载到本地或复制直链。

### 挂载管理

- 查看所有存储及其状态，启用、禁用存储，重新加载单个或全部存储。
- 新建和编辑存储时，表单会根据所选驱动自动生成，字段名称和说明已翻译成中文；密码、密钥一类的字段默认隐藏显示。

### 任务、用户与系统设置

- 任务中心可以查看上传、复制、移动、离线下载等任务，按状态和类型筛选。
- 用户管理可以新建、编辑、禁用、删除用户，设置角色、基础路径和各项权限，也可以为用户关闭两步验证。
- 系统设置按分组查看和修改 OpenList 站点的全局配置。

### 外观

支持浅色、深色和跟随系统三种主题；Android 12 及以上可以开启「动态配色」，跟随壁纸取色。
